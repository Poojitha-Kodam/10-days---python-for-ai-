# Python for Agentic AI — 10 Day Learning Journey

A hands-on, project-based path through Python fundamentals into
building real AI agents: tool-calling, async, manual agent loops,
LangChain, and file persistence — using Google's Gemini API.

## Structure
- `day 1,2,3,4,5/` — Python fundamentals, classes, first API calls
- `day6/` — Automatic tool-calling
- `day7/` — Async/await
- `day8/` — Manual agent loops built from scratch
- `day9/` — LangChain framework
- `day10/` — File persistence + capstone finance agent
